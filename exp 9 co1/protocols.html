Observing Internet Protocols Using Browser Developer Tools

Interactive Demonstration

Objective

This webpage demonstrates how HTTP requests and responses can be observed using Browser Developer Tools. Click the button below to send an HTTP GET request.

No request has been made yet.

How to Observe the Protocol

Step Action
1 Press F12 to open Browser Developer Tools.
2 Open the Network tab.
3 Click the Send HTTP Request button.
4 Select the request in the Network panel.
5 Observe Request URL, Method, Status Code, Headers, Timing, and Response.

Expected Observation

  • Protocol: HTTPS
  • Request Method: GET
  • Status Code: 200 OK
  • Response Format: JSON
  • Headers: Request & Response Headers
  • Network Timing Information
